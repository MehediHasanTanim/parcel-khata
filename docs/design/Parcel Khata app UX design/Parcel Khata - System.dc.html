Rules shown above

  • Order follows the visual top→bottom, start→end; FAB comes after content, nav last.
  • Every icon-only control carries a text label for TalkBack / Voice Access.
  • Status is never colour alone: icon + word + colour.
  • Money is read as “taka”, with the sign: “minus 440 taka”.
  • Row targets are the full row, not the chevron.

Dynamic type & motion

  • Layout holds at 200% text; rows grow, nothing truncates money.
  • Reduce-motion: transitions become instant, pulses stop, spinners keep rotating slowly.
  • Errors are announced as live regions, focus moves to the first invalid field.
